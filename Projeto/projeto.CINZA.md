# Projeto Cinza
# Descrição do projeto:
O projeto será um site de trocas de itens colecionavéis da cultura pop como discos de vinis, CDS e livros
# Fluxo de uso:
1. Usuario cria uma conta
2. Faz login
3. Cadastra os itens da coleção
4. Procura itens desejados
5. Entra no perfil da pessoa 
6. Entra em contato pelo número disponibilizado no perfil
## Descrever as telas:
### Tela inicial
- logo
- Barra de pesquisa
- Categorias
- Botão de login
### Perfil
- foto
- Informações
- Coleções
### Catálogo 
- lista de itens
- Filtros
### Detalhe dos itens
- Fotos
- Descrição
- Estado de conservação
- botão que direcion para "Perfil da pessoa"

# Ideias
- Sistema da gamificação
- Lista de desejos
- Ranking dos melhores colecionadores
- Histórico de trocas
- Conquistas
